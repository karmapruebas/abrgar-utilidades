# Plugin abrgar-utilidades

## Descripción
Plugin personalizado creado para la Práctica 4 de WordPress.

Añade varias funciones al blog:
- Muestra una caja de contacto al final de las entradas.
- Permite mostrar el año actual mediante el shortcode [anio].
- Oculta la versión de WordPress del código fuente.
- Personaliza la pantalla de acceso de WordPress.

## Instalación
1. Copiar la carpeta abrgar-utilidades en wp-content/plugins/.
2. Entrar en Plugins > Plugins instalados.
3. Activar el plugin abrgar-utilidades.

## Dependencias
- WordPress.
- Tema hijo abrgar-hijo para los estilos de la caja de contacto
  y para utilizar el shortcode [anio] en el pie de página.

## Pruebas realizadas
- CP-01: caja de contacto en entradas, no en páginas.
- CP-04: shortcode [anio].
- CP-05: ocultación de la versión de WordPress.
- CP-06: personalización de la pantalla de acceso.
